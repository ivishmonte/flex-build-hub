# ТЗ для Lovable: лендинг-портфолио специалиста по вайбкодингу

Создай современный адаптивный одностраничный лендинг-портфолио специалиста по **вайбкодингу, AI-продуктам, MVP и автоматизациям**.

Главная задача лендинга — быстро показать экспертизу, стиль работы, конкретные услуги и примеры проектов, вызвать доверие и привести посетителя к контакту через Telegram или Email.

Используй загруженный референс как основное визуальное направление.

## 1. Общая визуальная концепция

Стиль: современный premium-tech / AI / SaaS.

Ориентируйся на референс:

* глубокий почти чёрный или тёмно-синий фон;
* крупная белая типографика;
* акцентные градиенты: синий → фиолетовый → розовый → оранжевый;
* мягкое цветное свечение на фоне;
* glassmorphism;
* полупрозрачные карточки;
* тонкие светящиеся рамки;
* мягкие тени;
* крупные скругления;
* минимум визуального шума;
* ощущение дорогого digital-продукта;
* интерфейс должен выглядеть как настоящий продукт, а не как шаблонный сайт.

Не копировать референс буквально. Использовать его композицию, атмосферу, цветовую систему и характер интерфейса.

## 2. Типографика

Использовать современный sans-serif шрифт: **Inter, Manrope, Geist или аналогичный**.

Размеры ориентировочно:

* H1 desktop: 64–72 px;
* H1 mobile: 38–44 px;
* H2 desktop: 40–48 px;
* H2 mobile: 30–34 px;
* H3: 20–24 px;
* основной текст desktop: 17–18 px;
* основной текст mobile: **не меньше 16 px**;
* подписи: 14–16 px.

Заголовки плотные, выразительные.

Не делать длинные строки текста. Максимальная ширина текстового блока около 650–720 px.

# 11. Кнопка «Купить курс»

Дополнительно реализовать универсальный компонент основной CTA-кнопки:

**Купить курс**

Она должна использоваться там, где в дальнейшем можно будет добавить продажу продукта или курса.

### Default

* яркий фиолетово-розово-оранжевый градиент;
* белый текст;
* высота около 52 px;
* крупное скругление;
* лёгкая тень и свечение.

### Hover

При наведении:

* кнопка становится примерно на 8–12% темнее;
* поднимается вверх на 2–3 px;
* тень слегка усиливается;
* transition около 200 ms.

### Focus

При keyboard focus появляется заметная синяя обводка толщиной 2–3 px.

Использовать `:focus-visible`.

### Disabled

* серый фон;
* приглушённый текст;
* отсутствие hover;
* отсутствие движения;
* `cursor: not-allowed`;
* кнопка не выполняет действие.

### Loading

При активации loading:

показывать spinner + текст:

**Обработка...**

На время loading:

* повторное нажатие невозможно;
* button disabled;
* добавить `aria-busy="true"`.

Ширина кнопки при смене текста не должна изменяться.

Использовать настоящий HTML `<button>`.

На mobile:

* высота минимум 52 px;
* текст минимум 16 px;
* ширина до 100%;
* удобное нажатие одним пальцем.

# 13. Анимации

Добавить аккуратные микроанимации.

При появлении секций:

* fade-in;
* лёгкое движение снизу вверх;
* без сильных эффектов.

Карточки:

* translateY при hover;
* небольшое усиление градиентной рамки;
* плавные transition.

Dashboard в Hero:

может иметь очень лёгкое floating-движение.

Продолжительность большинства эффектов:

`180–350 ms`.

Обязательно учитывать:

`prefers-reduced-motion`

и отключать лишние движения для пользователей, которым они нежелательны.

# 14. Адаптивность

Лендинг проектировать **mobile-first**.

Breakpoints ориентировочно:

* mobile: до 767 px;
* tablet: 768–1023 px;
* desktop: от 1024 px.

На mobile:

* Hero строго вертикальный;
* текст Hero сверху;
* изображение снизу;
* карточки проектов вертикально;
* карточки услуг вертикально;
* timeline вертикальная;
* CTA-кнопки крупные;
* основной текст минимум 16 px;
* область клика интерактивных элементов минимум 44×44 px;
* боковые отступы примерно 20 px;
* никаких элементов за пределами viewport;
* никаких микроскопических подписей;
* никаких горизонтальных таблиц;
* отсутствие горизонтального скролла.

# 15. UX и доступность

Использовать семантические HTML-элементы:

`header`

`nav`

`main`

`section`

`footer`

Использовать один `h1`.

Соблюдать правильную иерархию `h2` и `h3`.

Для всех кнопок и ссылок:

* keyboard navigation;
* focus-visible;
* достаточный контраст;
* понятный hover;
* понятное активное состояние.

Для изображений добавить `alt`.

Декоративные изображения не должны мешать screen reader.

---

# 16. Производительность

Лендинг должен ощущаться быстрым.

Не перегружать его тяжёлыми JS-анимациями.

Оптимизировать изображения.

Использовать WebP/AVIF там, где возможно.

Lazy-load для изображений ниже первого экрана.

Не использовать фоновые видео.

Не создавать тяжёлые canvas/WebGL-эффекты без необходимости.

Цель:

быстрое отображение первого экрана даже на мобильном интернете.

---

# 17. Технические требования

Использовать современный компонентный подход.

Предпочтительно:

**React + TypeScript + Tailwind CSS**

или стандартный стек Lovable.

Повторяющиеся UI-компоненты вынести отдельно:

* `Button`
* `ProjectCard`
* `ServiceCard`
* `ProcessStep`
* `SectionHeading`

Контактные данные, проекты и услуги не хардкодить хаотично внутри JSX.

Вынести их в понятные структуры данных, чтобы их было легко менять.

Например:

`projects`

`services`

`processSteps`

`contactLinks`

# 19. Общие ограничения

Не использовать:

* шаблонные стоковые фотографии людей;
* слишком много иконок;
* яркие градиенты на каждом элементе;
* огромные пустые пространства без функционального смысла;
* неон на каждом тексте;
* мелкий серый текст с плохой читаемостью;
* перегруженные фоновые анимации;
* горизонтальный скролл;
* декоративные элементы, ухудшающие mobile UX.

Главное визуальное впечатление:

**технологично, дорого, современно, уверенно.**

Пользователь должен за первые несколько секунд понять:

**специалист создаёт современные AI-продукты, умеет быстро запускать MVP и может взять реальную задачу от идеи до работающего решения.**

Для Hero и общего арт-дирекшена ориентируйся на **загруженный референс**, особенно на сочетание глубокого тёмного фона, белой типографики, крупных продуктовых mockup-интерфейсов и мягких фиолетово-розово-оранжевых свечений.
